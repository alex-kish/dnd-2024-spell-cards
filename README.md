# Карточки заклинаний D&D 2024

Простое веб-приложение для просмотра и печати карточек заклинаний для игры Dungeons & Dragons 2024.

## Возможности

- 📚 **Каталог заклинаний** — компактный список из 391 заклинания, описание раскрывается по клику
- 🔍 **Поиск и фильтрация**:
  - По русскому или английскому названию
  - По уровню, классу и источнику
  - Только с концентрацией или только ритуалы
- ✅ **Выбор для печати**:
  - Заклинания отмечаются галочкой, выбранные видны в боковой панели по уровням
  - Экспорт и импорт выбора в JSON
  - Автоматическое сохранение в localStorage
- 🖨️ **Печать карточек**:
  - Предпросмотр листов A4 и итог «заклинаний → карточек → страниц»
  - 1–4 колонки и 1–4 ряда карточек на листе
  - Длинные описания автоматически переносятся на следующие карточки
  - Подгонка шрифта для каждого заклинания: кнопки «−/+» и «Уместить»
  - «Уместить всё» подбирает шрифт для всех заклинаний с учётом минимального размера
  - Оформление: размеры шрифтов шапки, цвет и скругление карточек

## Технологии

- **HTML5** — структура страницы
- **CSS3** — стили и адаптивность
- **Vanilla JavaScript** — вся логика приложения
- **JSON** — данные заклинаний

Без использования сторонних библиотек, сборщиков и фреймворков.

## Использование

1. Откройте `index.html` в браузере
2. Найдите нужные заклинания с помощью поиска и фильтров
3. Отметьте их галочками — они появятся в панели «Выбрано»
4. Перейдите во вкладку «Карточки»
5. Выберите сетку и шрифт, при необходимости подгоните шрифт отдельных заклинаний или нажмите «Уместить всё»
6. Нажмите «Распечатать»

## Хранение данных

Все данные сохраняются локально в браузере через localStorage:
- Выбранные заклинания
- Настройки печати и размеры шрифтов для каждой карточки
- Настройки фильтров
